### ⚡ Engineering Principles

* **Correctness > Vibes:** Whether it's integer-paise financial math, idempotency keys, or deterministic tool schemas, I design systems that fail gracefully instead of silently corrupting state.
* **Evals & Tests First:** An LLM pipeline without evaluation and API integration tests is just guessing.
* **Ship End-to-End:** I like owning the full loop—from database schema and async workers to clean APIs and clear documentation.
